# TPs du cours de Modélisation géométrique

Dépot github contenant un projet Unity contenant les rendues de chaque TPs :

1. TP1
   Aller dans la scène "SampleScene", pour y retrouver un gameObject vide "TP1" auquel plusieurs gameObjects enfants y sont attachés, correspondant chacun à chaque exo du TP. On peut activer chaque gameObject enfant dans l'inspecteur et modifier les paramètres du script attaché, pour voir le rendu.
